# Bringing Japan 2 U

A premium pre-launch storefront for a Japan-sourcing business focused on Japanese collectibles, Pokémon TCG, anime goods, and culture finds.

## Current state

The active redesign lives on `redesign-v1`. The original site remains on `main` until the redesign is reviewed and approved.

### Implemented

- Premium responsive homepage
- Shop search and category filters
- Local shopping bag prototype
- Product detail pages
- Japan sourcing request flow
- Our Story, FAQ, Policies, and Contact pages
- Mobile navigation
- Branded 404 and favicon
- Sitemap, robots file, and web manifest
- Automated HTML and internal-link checks

## Important pre-launch note

The storefront is currently a preview. Checkout is intentionally disabled. No card or payment information should be collected until a secure payment provider and final policies are connected.

## Local preview

This is a static site. Open `index.html` in a browser, or serve the directory with any simple local HTTP server.

## Quality check

```bash
npm install
npm run check
```

## Launch checklist

1. Replace concept art with final product photography.
2. Confirm actual inventory, SKU names, quantities, dimensions and condition.
3. Finalize shipping destinations and rates.
4. Finalize return/refund and privacy language.
5. Connect secure checkout.
6. Connect a custom domain.
7. Replace preview URLs in `sitemap.xml` with the final domain.
8. Run a full mobile/desktop checkout test before taking the first payment.
